# Pilti CLI Releases & Distribution

Official public release repository for the **PiltiSmart CLI (`pilti`)**.

## ⚡ 1-Line Universal Installers

### 🐧 Linux & 🍎 macOS (Bash / Zsh)
```bash
curl -fsSL https://raw.githubusercontent.com/PiltiSmart/pilti-releases/main/install.sh | bash
```

### 🪟 Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/PiltiSmart/pilti-releases/main/install.ps1 | iex
```
